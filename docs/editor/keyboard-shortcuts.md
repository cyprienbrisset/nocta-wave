# Raccourcis Clavier

> Liste complète des raccourcis clavier de WS-Flows.

## Vue d'Ensemble

WS-Flows propose de nombreux raccourcis clavier pour accélérer votre travail. Les raccourcis sont inspirés des conventions standards.

## Personnaliser les Raccourcis

Actuellement, les raccourcis ne sont pas personnalisables. Cette fonctionnalité est prévue pour une version future.

## Conseils

### Productivité

1. **Utilisez `Tab`** pour ajouter rapidement des nodes
2. **`F`** pour recentrer quand vous êtes perdu
3. **`Ctrl + Z`** fréquemment - l'historique est généreux
4. **`Space`** en mode replay pour contrôler la lecture

### Éviter les Conflits

Certains raccourcis peuvent entrer en conflit avec le navigateur :
- `Ctrl + W` (fermer l'onglet) → Évité intentionnellement
- `Ctrl + T` (nouvel onglet) → Évité intentionnellement
- `F5` → Intercepté par l'app, n'actualise pas la page
